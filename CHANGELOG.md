# Changelog

## 2.6.0
- **Enterprise app:**
  - desktop sidebar and an Overview page (security posture, metrics, protection status, recommended actions, recent activity);
  - Data policies, Audit log and Verification sections;
  - no XP or emoji in the product UI;
  - guided setup instead of quests.
- **Audit export:** CSV and JSON, with spreadsheet-formula neutralisation.
- **Visual system:** calm slate and teal palette, flat colour only (no gradients), new type scale and spacing; app and extension icons redrawn.
- **Pip:**
  - always up to something (paces, hops, spins, chases a spark, dances, waves, stretches, peek-a-boo);
  - asks for pats; grumpy when over-petted;
  - pauses while your pointer is on him;
  - flat redraw.
- **Sounds:** recorded sounds supported (`docs/SOUNDS.md`), with synthesized fallback.
- **Docs:** `docs/ENTERPRISE.md` (architecture, data inventory, 12 guardrails, deployment, operations, framework mapping); CI workflow; one source tree (no symlinks).

## 2.5.0
- Pip redrawn from the character sheet: 16 expressions, Protecting in green; two-gesture interaction.

## 2.4.0
