For security teams

Guardrails you can audit.

Everything runs unprivileged on the device. Content is inspected locally and never stored. Every control fails closed. The full architecture, data inventory and framework mapping are in ENTERPRISE.md.

Inspect before transmission

Capture-phase interception of send, upload, drop and paste, before site code runs.

Local-only analysis

Text, PDF by page, DOCX and image OCR on the device. No cloud classifier.

Fail closed

No agent, no dialog or no answer means Cancel. Telegram unreachable means Claude actions are denied.

Out-of-band approval

Claude tool calls wait for your phone. 24 h sessions, nonce-checked callbacks, instant revoke.

Minimum disclosure

Telegram sees rule names and masked samples only. Passwords never leave the device.

Content-free audit

Every decision logged without content. Export CSV or JSON for your SIEM.

Install

One minute. One double-click.

You need macOS or Linux, Python 3.10+, and Chrome, Edge, Brave, Arc or Chromium. The installer asks nothing. It connects your browsers, starts at login and opens Chrome's extension page with the folder path already copied.

STEP 1

Download & unzip

Get walled-shield-{{V}}-installer.zip from the releases page and unzip it.

STEP 2

Double-click

Install Walled.command. First time: right-click → Open → Open, because the file came from the internet.

STEP 3

Three clicks in Chrome

Developer mode → Load unpacked → ⌘⇧G ⌘V Enter → Select. Done.

Troubleshooting

macOS blocks the installer: right-click Install Walled.command → Open → Open.

No dialog on ChatGPT: check the extension is on (walled extension), then reload the tab.

Telegram stopped asking: approvals pause after 24 h. Use the renew link, or run walled mcp renew.

Pip isn't on the desktop: he needs pywebview (on Linux also GTK or Qt); otherwise he lives in the browser corner.
